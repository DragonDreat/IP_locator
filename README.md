# IP Locator - Educational Purpose

This IP Locator is a small python application made for educational Purposes. It was actually one of mines first Python projects!

## Installation

1. Download it from the release, and if you want to test it then you have to download the open source code!
2. When you download the .exe just run it, and the console will pop up, and that's it!
3. And enjoy it, and test it as much as you like!


## Usage
It's usually used for checking IP addresses, it is really easy to use it. You just have to run it and copy paste the ip address..
